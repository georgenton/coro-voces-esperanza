# Evidencia visual sintética

Estas capturas fueron generadas el 3 de octubre de 2026 con Playwright, Chromium y la base local desechable `voces_test`. No contienen datos reales del coro.

Convención: `<pantalla>-<ancho>-<tema>.png`.

- pantallas: `dashboard`, `movimientos`, `cuotas`;
- anchos: `390`, `1024`, `1440` píxeles;
- temas: `light`, `dark`.

La prueba que las genera también rechaza overlays de Next y mensajes de consola con nivel `error`. Los controles funcionales se validan por separado en `tests/e2e/authenticated-reports.spec.ts`.
